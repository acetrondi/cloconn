# Blog Thumbnails

This folder is for blog post thumbnail images.

## Adding Images

Add blog thumbnail images here with descriptive filenames, for example:

- `choosing-major.jpg`
- `study-abroad-checklist.jpg`
- `writing-sop.jpg`

Update the `thumbnail` field in `/src/data/blogs.json` to reference these images:

```json
{
  "thumbnail": "/blogs/choosing-major.jpg"
}
```

## Recommended Specifications

- **Format:** JPG or PNG
- **Dimensions:** 800x600px (4:3 ratio) or 1200x630px (Open Graph)
- **File Size:** < 200KB (optimized for web)
- **Quality:** 80-85% compression
