# Testimonial Avatars

This folder is for testimonial avatar images.

## Adding Images

Add avatar images here with descriptive filenames, for example:

- `aarav.jpg`
- `priya.jpg`
- `rohan.jpg`

Update the `avatar` field in `/src/data/testimonials.json` to reference these images:

```json
{
  "avatar": "/avatars/aarav.jpg"
}
```

## Recommended Specifications

- **Format:** JPG or PNG
- **Dimensions:** 200x200px (square)
- **File Size:** < 50KB
- **Style:** Circular crops work best
